# Doc–MLIR–GraphDB: канон в репо

**В этом репозитории** канонический путь к артефактам Doc–MLIR–GraphDB — **этот каталог** (`.cursor/artifacts_mlir_graphdb`).

- **mlir/** — диалекты и трансформации (реестр в [mlir/README.md](mlir/README.md)).
- **graphdb/** — схема KG и примеры SPARQL/Turtle (см. [graphdb/README.md](graphdb/README.md)).

Опционально в портфолио-репо используется `docs/sdlc/_KG_MLIR`; при его отсутствии все ссылки ведут сюда.
