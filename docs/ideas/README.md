## docs/ideas

This folder contains **branch-specific, forward-looking, or exploratory** documentation that is **not present on `origin/main`**.

The intention is to keep the top-level `docs/` layout aligned with `origin/main`, while still preserving design notes and longer-term proposals that may become relevant once other changes are upstreamed.

Contents:

- `01_Architecture/`: architecture and design documents that are proposals and/or reflect features not yet on `origin/main`.
- `solutions/`: research/idea writeups and longer-term solution sketches.
- `issues/`: issue-specific notes and investigations.
- `pr_descriptions/`: PR writeups kept for reference.
