# TRID DMA barriers: семантика

Краткая спецификация для опции `use-trid-barriers` пасса convert-ttl-to-ttkernel.

- **Уникальность:** TRID должен быть уникален для каждой незавершённой копии (outstanding copy); порядок числовых значений TRID семантически не важен.
- **Детерминизм:** Генерация TRID может быть недетерминированной при параллельном применении паттернов (greedy rewriter); достаточно гарантировать уникальность в рамках корректного ожидания барьера.

Подробности низкоуровневой семантики барьеров и NOC — в tt-metal (LLK/hardware docs).
