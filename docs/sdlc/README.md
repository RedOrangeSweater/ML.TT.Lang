# SDLC (tt-lang)

Корень SDLC для tt-lang. Доки по связанным репозиториям (tt-metal, LLK) хранятся здесь и связаны с основным процессом. 01_tt_metal и 02_llk — кросс-репо точки входа; канонические расположения — в репо tt-metal и в tt_llk соответственно.

- **Основной SDLC tt-lang**: [00_Main/](00_Main/).
- **Доки по tt-metal**: [01_tt_metal/](01_tt_metal/) — статус, BA, архитектура, спек, QA по репо tt-metal.
- **Доки по tt_llk (LLK)**: [02_llk/](02_llk/) — статус и спек по низкоуровневым ядрам LLK (репо внутри tt-metal).

**Реестр**: [00_registry.json](00_registry.json).
